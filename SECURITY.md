# Security policy

Security fixes target the current `master` branch and latest release.

Report suspected vulnerabilities through this repository's private GitHub
security-advisory flow. Do not open a public issue for source deletion risk, path
traversal, command injection, transfer-verification bypass, credential exposure, or
unauthorized federation access.

Sanitize diagnostics before sharing them. Never attach live configuration, SSH material,
queue databases, sync history, catalogs, tracker details, Keychain values, or credentials.
